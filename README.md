# JdClicker — автонажатие зелий для Jade Dynasty

Утилита по таймеру жмёт клавиши ячеек с зельями. Делает то же, что раньше скрипт Clickerman `hil_1.cms` (0, 9, 8 по кругу), но:

- **жмёт только клавиатурой.** Мышь, курсор и камера не трогаются, фокус окна не перехватывается;
- **жмёт только в игру.** Если активно другое окно (браузер, Discord, рабочий стол), нажатий нет;
- **не спамит в чат.** Пока открыта строка ввода чата, нажатия не идут (подробнее ниже);
- у каждой клавиши свой интервал, длительность нажатия настраивается;
- хоткей вкл/выкл, звук при включении и выключении, цветной индикатор поверх игры и иконка в трее;
- настройки хранятся в `settings.json` рядом с exe и применяются сразу, без перезапуска.

## Запуск

1. Положите `JdClicker.exe` в отдельную папку, например `C:\Games\JdClicker\`. Там же появится `settings.json`.
   Не кладите exe в `Program Files`: туда нельзя писать без прав администратора.
2. Запустите `JdClicker.exe`. Окна не появится, только серый кружок в трее (возле часов). Устанавливать .NET не нужно, всё внутри exe.
3. Зайдите в игру и нажмите **F11**. Прозвучит сигнал «вверх», индикатор станет зелёным: клавиши жмутся.
4. Ещё раз **F11** — сигнал «вниз», индикатор серый: выключено.

При первом нажатии хоткея в игре JdClicker запоминает процесс игры. Дальше хоткей, нажатый в другой программе, ничего не включит, а только пискнет ошибкой. Сбросить привязку: «Настройки → Защита → Забыть».

**Если игра запущена от администратора**, JdClicker тоже нужны права администратора, иначе Windows не пропустит нажатия. Индикатор покажет красное «НУЖЕН АДМИН». Нажмите правой кнопкой на иконку в трее → «Перезапустить от администратора».

## Индикатор поверх игры

| Цвет | Надпись | Что значит |
|---|---|---|
| серый | `ВЫКЛ  F11` | выключено |
| зелёный | `ВКЛ` | жмёт |
| жёлтый | `ЧАТ — пауза` | открыт чат, не жмёт |
| жёлтый | `ПАУЗА` | зажат Shift / Ctrl / Alt, не жмёт |
| красный | `НУЖЕН АДМИН` | игра запущена от администратора, а JdClicker нет |

- Индикатор не забирает фокус у игры.
- Чтобы переместить, тяните его левой кнопкой. Положение запоминается относительно окна игры и сохраняется при перемещении и изменении размера окна.
- Правая кнопка мыши открывает то же меню, что и в трее.
- Индикатор виден только когда игра на переднем плане. Отключается в настройках.

## Защита от спама в чат

JdClicker следит за **вашими** нажатиями, ничего не нажимая сам:

- **Enter** переключает состояние «чат открыт / закрыт»;
- **Esc** означает «чат закрыт»;
- **клик левой кнопкой по игре** означает «чат закрыт» (игра закрывает строку ввода при клике мимо неё);
- **клик в строке ввода чата** означает «чат открыт», если вы указали поле чата: меню в трее → «Указать поле чата…» → выделите мышью строку, где печатается текст.

Пока чат открыт, нажатия не отправляются. После закрытия чата JdClicker ждёт 150 мс, чтобы игра успела закрыть поле ввода.

Каждое своё нажатие JdClicker проверяет ещё раз в момент, когда оно проходит через Windows, в том же порядке, в каком его увидит игра. Если вы успели нажать Enter раньше, нажатие выбрасывается и до игры не доходит.

**Ограничения:**

- Если поле чата не указано, а вы открыли чат кликом мыши, JdClicker об этом не узнает. Откройте чат через Enter или укажите поле чата.
- Если Enter нажат не для чата (например, подтверждение в диалоге NPC), состояние может перевернуться. Это видно по индикатору: жёлтый «ЧАТ», когда чата нет. Исправляется двойным F11 (выкл → вкл): включение сбрасывает состояние на «чат закрыт».

## Настройки

Окно настроек: двойной клик по иконке в трее или «Настройки…» в меню. Изменения применяются сразу.

| Настройка | По умолчанию | Пояснение |
|---|---|---|
| Зелья: клавиша | `8`, `9`, `0` | До 6 клавиш. Кликните в поле и нажмите клавишу; можно с модификатором, например `Alt+1`. Backspace — очистить. Enter и Esc назначить нельзя: ими открывается и закрывается чат. |
| Зелья: жать каждые, мс | 300 | Как часто жать эту клавишу. 1000 мс = 1 сек. Минимум 20. |
| Галочка слева | вкл | Выключает клавишу, не стирая её. |
| Длительность нажатия, мс | 30 | Сколько клавиша «зажата». Если игра иногда не реагирует, увеличьте до 40–60. |
| Пауза между разными клавишами, мс | 40 | Чтобы нажатия не слипались. Полный круг из 3 клавиш занимает не меньше 3 × (30 + 40) = 210 мс. |
| Хоткей вкл/выкл | `F11` | Кликните в поле и нажмите нужное сочетание (например, `Ctrl+F1`). Работает и из игры. |
| Звук при вкл/выкл | вкл | Сигнал «вверх» при включении, «вниз» при выключении, двойной низкий — ошибка. |
| Индикатор поверх игры | вкл | Плашка с цветным кружком. |
| Не жать, пока открыт чат | вкл | Защита от спама в чат (см. выше). |
| Указать поле чата / Сбросить | не задано | Область строки ввода, нужна, чтобы ловить открытие чата кликом. |
| Не жать, пока зажаты Shift / Ctrl / Alt | вкл | Иначе `8` превратится в `Shift+8` и т. п. |
| Окно игры / Забыть | пусто | Процесс игры, запоминается при первом F11 в игре. |

Внизу окна показано состояние и счётчики: сколько нажатий дошло до игры и сколько отсекла защита.

### settings.json

Файл можно править блокнотом прямо во время работы: изменения подхватятся сами. Если в файле ошибка, останутся прежние настройки, а в трее появится сообщение.

```json
{
  "keys": [
    { "enabled": true, "key": "8", "intervalMs": 300 },
    { "enabled": true, "key": "9", "intervalMs": 300 },
    { "enabled": true, "key": "0", "intervalMs": 300 },
    { "enabled": false, "key": "", "intervalMs": 300 },
    { "enabled": false, "key": "", "intervalMs": 300 },
    { "enabled": false, "key": "", "intervalMs": 300 }
  ],
  "holdMs": 30,
  "gapMs": 40,
  "toggleHotkey": "F11",
  "sound": true,
  "overlay": true,
  "overlayX": 300,
  "overlayY": 6,
  "pauseInChat": true,
  "chatArea": null,
  "skipWhenModifiersHeld": true,
  "gameProcess": ""
}
```

Названия клавиш: `0`–`9`, `-`, `=`, `F1`–`F12`, `A`–`Z`, `Num0`–`Num9`, `Space`, `Tab`, `Insert`, `Home` и т. д., с модификаторами `Ctrl+`, `Alt+`, `Shift+`.

## Про ячейки на панели навыков

JdClicker жмёт **клавиши**, а не ячейки. Ячейка «нажимается» без мыши, только если на неё назначена клавиша в игре:

- нижний ряд — `1`…`0`, `-`, `=`. Зелья можно переложить в любую его ячейку, в том числе в свободные `-` и `=`, и вписать эту клавишу в JdClicker;
- второй ряд — `F1`…`F8` и дальше;
- третий и четвёртый ряды. Если в настройках управления игры на них можно назначить клавиши (например, `Alt+1`), назначьте и впишите в JdClicker. Если назначить нельзя, эти ячейки нажимаются только мышью, и JdClicker их не достанет.

Нажатие клавиши не двигает курсор и камеру и не сбивает движение: если вы держите `W`, персонаж продолжит идти.

## Сборка из исходников

Нужен .NET 8 SDK.

```
dotnet publish src/JdClicker -c Release -o out
```

Результат — один файл `out/JdClicker.exe` (~65 МБ, .NET встроен). Тот же exe собирается в GitHub Actions (вкладка Actions → артефакт `JdClicker`).

## Риски

Сервер частный и «для своих», но учтите: любая программа, которая жмёт клавиши за игрока, может нарушать правила сервера. Нажатия через `SendInput` технически видны как программные. Решение о запуске за вами.
